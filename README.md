## Setup and run

Install Flutter and the Android SDK or a supported web browser, then check the environment with `flutter doctor`.

From the app folder you want to run:

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

To target a browser, use `flutter run -d chrome`. Each app also has its own README with assignment details.

Source, assets, platform configuration, and application dependency lockfiles are tracked. Build output, dependency caches, machine-specific SDK paths, and signing keys are ignored.

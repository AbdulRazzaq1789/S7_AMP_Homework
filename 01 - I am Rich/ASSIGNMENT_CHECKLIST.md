# Week 01 — I Am Rich App

This project implements the **I Am Rich App**, as requested in place of Lecture 01's original setup-focused homework.

## App task

- [x] A runnable Flutter application with `main()` and `runApp()`.
- [x] `MaterialApp`, `Scaffold`, and `AppBar`.
- [x] Distinctive full-screen presentation with "I AM RICH" text.
- [x] Bundled, offline diamond image in `assets/images/diamond.png`.
- [x] Properly declared image asset in `pubspec.yaml`.
- [x] A project with separate theme, screen, and widget source files.
- [x] A widget tree diagram in `docs/WIDGET_TREE.md`.
- [x] Widget tests for content, theme, and narrow viewport.
- [ ] Run `flutter doctor` locally and resolve your SDK/device problems.
- [ ] Run the app on an emulator or device; take your own screenshots.

The actual Lecture 01 homework additionally requests Flutter installation, a project named `Lecture1_flutter`, lifecycle logging, and written lifecycle comparisons; those are **not** part of this replacement app request.
